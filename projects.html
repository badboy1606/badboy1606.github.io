RubikNet — RL Powered Rubik's Cube Solver

Overview: Built an intelligent Rubik's Cube solving system integrating Deep Reinforcement Learning, A*, Beam Search, and robotic actuation.
Core Innovation: Designed a cube simulator and dataset generator in Python to train policy and value networks using Autodidactic Iteration (ADI).
Performance: Achieved 99% solve accuracy up to 8 scrambles and 80% accuracy for 10–12 scrambles using reward engineering and policy optimization.
Hardware Integration: Engineered an ESP32-controlled platform using NEMA 17 stepper motors and DRV8825 drivers. Integrated OpenCV-based vision for cube detection and real-time UART communication.
Tech Stack: Python, PyTorch, OpenCV, ESP32, ESP-IDF, DRV8825, NEMA 17, MCTS

Morse Code Detector using EOG Signals

Overview: Developed an assistive communication system using Electrooculography (EOG).
Signal Acquisition: Recorded EOG signals using BioAmp EXG Pill hardware.
Signal Processing: Detected and classified short and long eye blinks mapped to Morse code.
Interface: Built a Streamlit-based real-time decoding interface in Python.
